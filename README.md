# 项目特征清洗与清单生成工具

离线单文件 HTML 工具，把工程量清单汇总表清洗成「项目特征清单」，支持反查、模板自定义、Excel 导出（含样式）。

## 功能
- 导入汇总表（.xlsx/.xls/.csv），一键数据清洗（拆分合并单元格、构建类型列、拆“-”列、最佳列宽、边框）。
- 项目特征模板：分类 / 项目特征格式 / 工程量名称映射 / 工程量映射，支持 {列名} 占位符与 {对应工程量名称表头名}/{对应工程量表头名}。
- 一键生成清单，相同项目特征自动汇总工程量，反查列出全部来源。
- 按清单样式导出 Excel（项目特征表置顶 + 11 张清洗表打包）。
- 内置「下载广联达 GQI2021 报表设置」按钮（GQI2021安装报表设置.BSZ）。

## 使用
直接用浏览器打开 index.html 即可，无需服务器、无需联网、无需安装。
若使用「下载广联达 GQI2021 报表设置」按钮，请保持 GQI2021安装报表设置.BSZ 与 index.html 在同一目录（本仓库已包含）。

## 源码
- index.html —— 构建产物（SheetJS 内联，单文件离线可用）
- src/app.js —— 应用逻辑
- src/build_html.py —— 构建脚本（注入 SheetJS + app.js + CSS）
- src/_sheetjs.js —— xlsx-js-style 库
- GQI2021安装报表设置.BSZ —— 广联达报表模板
